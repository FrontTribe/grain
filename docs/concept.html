why now

Two trends just collided in every repo.

The signal came from watching maintainer communities this month. Both of these are real, and together they make an unmet need.

Trend 01

AI now commits on its own

Autonomous agents open PRs, keep tool-activity logs, and push commits directly into repos. Code in a tree is no longer obviously human.

"@OmniBlocks/boxy peace was never an option"— a developer replying to an AI bot working his repo, GitHub
Trend 02

Maintainers turned wary

Projects are rewriting contribution policy to demand transparency about what an AI wrote and who stands behind it.

"To better reflect the community's AI-skeptical ('wary') sentiment, the text of the policy itself has changed."— maintainer, Bevy engine policy PR

The gap between them is trust. Grain is the instrument that measures it.

what it outputs

No dashboard to learn. Grain meets developers where they already look — the badge, the PR, and a file in the repo.

how it reads the grain

Forensics, ranked by confidence.

Grain starts from hard evidence and only falls back to inference — and it reports a confidence score, never an accusation.

Explicit signals

Co-Authored-By trailers, agent commit signatures, *[bot] accounts, PR labels. Ground truth.

high confidence

Commit forensics

Burst timing, diff uniformity, size-to-message ratio — the "all at once" shape typical of agent output.

inferred

Convention diffing

Does the change respect the repo's own style and CODEOWNERS? An AI touching a human-owned path is the signal that matters.

inferred

Local model pass

Only for ambiguous diffs, and it runs client-side. Your code never leaves the machine.

privacy-first
Design principle: Grain reports signals, not verdicts. "62% of these lines carry AI signals" — never "this person cheated." That single choice is the difference between adoption and backlash.
the business, honestly

Open core. The instrument is free; the org tooling is paid.

The CLI is genuinely useful and genuinely MIT. Money lives where teams need policy, history, and compliance across many repos.
